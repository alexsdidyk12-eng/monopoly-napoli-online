# MONOPOLY: NAPOLI — 3D-игра + онлайн (2–8 игроков), один сервис на Render

Одна ссылка Render открывает игру. Тот же сервер обслуживает онлайн-комнаты (Socket.IO). Netlify не нужен.

## Структура
```
monopoly-napoli-online/
├── server.js        Express + Socket.IO: раздаёт public/, /health, комнаты, проверка действий
├── package.json     зависимости (express, socket.io, three@0.128.0), npm start
├── package-lock.json (появится после первого npm install — закоммитьте его)
├── README.md
├── .gitignore
└── public/
    ├── index.html   игра: локальный режим + онлайн-режим
    └── three.min.js Three.js r128 (копируется автоматически при npm install, см. ниже)
```

## Два независимых режима (главное меню)
* **🏠 Локальная игра** — 2–8 игроков на одном устройстве, с ботами, автосохранением; не требует сервера и интернета.
* **🌐 Онлайн-игра** — комнаты, до 8 реальных игроков, без ботов. Подключение к серверу начинается только при нажатии этой кнопки.

## Three.js r128
Игра написана под Three.js r128 (так сказано в коде, резервная ссылка тоже на r128). `index.html` подключает `three.min.js` по локальному пути. Файл берётся из npm-пакета `three@0.128.0` (версия закреплена точно) и автоматически копируется в `public/three.min.js` скриптом `postinstall` при `npm install` — в том числе на Render. Если хотите хранить файл в репозитории: после `npm install` закоммитьте `public/three.min.js`. Резервный CDN в `index.html` остался только на случай, если локальный файл не найден (тогда в логе сервера будет предупреждение).

## Как распаковать архив
1. Скачайте `monopoly-napoli-online.zip` и распакуйте (ПКМ → «Извлечь всё» на Windows; двойной клик на macOS; `unzip monopoly-napoli-online.zip` в терминале).
2. Должна получиться папка `monopoly-napoli-online` с файлами из структуры выше (без лишней вложенной папки).
3. Откройте терминал в этой папке.

## Проверка на компьютере
```
npm install
npm start
```
Откройте `http://localhost:3000` (две вкладки — для проверки комнат), `http://localhost:3000/health` должен вернуть `{"status":"ok",...}`.

## Render
New + → **Web Service** → выберите репозиторий.

| Настройка | Значение |
|---|---|
| Runtime | Node |
| Build Command | `npm install` |
| Start Command | `npm start` |
| Health Check Path | `/health` |
| Instance Type | Free (для старта) |

Переменные окружения (всё необязательно): `NODE_VERSION=20`; `AUTOPLAY_AFTER_MS` (45000) — когда сервер начинает ходить за отключённого игрока; `ABSENT_LIMIT_MS` (600000) — когда отключённый исключается из партии; `LOBBY_GRACE_MS` (60000); `ROOM_IDLE_MS` (1800000); `MAX_ROOMS` (200); `CORS_ORIGINS` — только если игру нужно открывать с другого домена. `PORT` Render задаёт сам.

После деплоя откройте адрес вида `https://ваш-сервис.onrender.com` — откроется игра; `/health` — проверка сервера. Прописывать адрес в коде не нужно: игра подключается к адресу, с которого открыта.

## Проверка онлайна с двух устройств
1. Телефон: откройте ссылку Render → «Онлайн-игра» → ник → «Создать комнату» (код из 5 символов или «Скопировать ссылку»).
2. Ноутбук: та же ссылка → «Онлайн-игра» → код → «Войти по коду» → «Готов».
3. На телефоне станет активна «Начать игру». Проверьте бросок, покупку, аренду, аукцион, сделку, обновление страницы (возврат на своё место).

## Важно знать
* Партии хранятся в памяти сервера — при перезапуске Render пропадают.
* Бесплатный Render засыпает после ~15 минут без запросов, первое открытие может занять до минуты.
* Онлайн-партия не затрагивает локальное сохранение: оно остаётся в браузере и доступно через «Продолжить игру».
